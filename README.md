# 🏈 Explosive Power & Speed Analytics

## 📌 Project Overview
As a Division I student-athlete and Information Science major, I am highly interested in the intersection of sports performance and quantitative data analysis. 

This project is a Python-based data analytics script that evaluates simulated NFL Combine metrics to identify correlations between speed (40-yard dash) and explosive lower-body power (vertical jump), as well as positional strength metrics.

## 🛠️ Tools & Technologies Used
- **Language:** Python
- **Data Manipulation:** `pandas` (Grouping, Aggregation, Data Cleaning)
- **Data Visualization:** `matplotlib`, `seaborn`

## 📊 Key Analytical Takeaways
1. **Speed vs. Explosive Power:** There is a strong negative correlation between 40-yard dash times and vertical jump height. (Athletes with higher vertical jumps tend to have faster sprint times, showcasing explosive power).
2. **Positional Variance:** Skill positions (WR, RB) dominate the explosive metrics, while linemen dominate static strength metrics (Bench Press).

## 🚀 How to view the project
The Python code is located in `nfl_analytics.py`. To run this script locally and generate the data visualizations, clone the repository and run:
`python nfl_analytics.py`
